## 〇、口径与图例

- **FE** = Team Reborn Energy 的能量单位；能耗单位 FE/t = 每游戏刻（tick，20/t 秒）消耗的 FE。
- **1 mol ≡ 1 B ≡ 1000 mB**（chemical/MolStock.java:25-26）；**1 桶 = 15 mol**（MolStock.java:34）；
  **1 金属锭 = 0.1 mol**（MolStock.java:52）。桶与锭刻意不对称，不是换算错误。
- **额定功率 vs 上限**：很多机器的「工作功耗」是随供电/来料浮动的值，本表给**额定**与**上限**两个口径。
- **待机功耗**列一律写明：0 = 真正不工作就不扣；「同工作」= 只要缓冲里有电就照扣。
- **本轮两条新口径**：
  - **逐配方功率**（还原炉 / 电解炉熔盐档）：炉子单刻扣多少电由**配方自己**带着走
    （`SmeltRecipe.powerFePerTick`，绝对值、不是倍率），**0 = 试剂驱动**：这一批一度电都不吃；
  - **逐反应单价**（电解炉溶液档）：每条电解反应自带 FE/mol 反应物
    （`MolBalance.Reaction.fePerMol`），机器只按实付得起的量推进、按实做功扣费。
- **bug#29**（docs/bug-log.md）：**离心机**空转扣电是**缺陷、已修**（待机 0 FE）；
  **磁选机**空转扣电是**特性、保留**（场强 = 本刻耗电 / 128，线圈通电即耗电），
  将来由**永磁磁铁升级**降低 / 免除这段基线（TODO）。
- tick() 与常量的行号以本仓库当前源码为准。

## 二、每台机器的公式与算例（可复算）

### 2.1 开采类

**矿脉抽取机**
- 扣电：tick() 中 running = **产物未满** && energy.amount >= ENERGY_PER_TICK（1024），成立才 energy -= 1024 并推进进度；产物九格塞满即停扣（bug#30，VeinExtractorBlockEntity.java:113-140）。
- 每件：ENERGY_PER_TICK × HARVEST_TICKS = 1024 × 20 = **20480 FE / 件**（旧 5120）。
- 算例：1 件/s 满速跑 1 分钟 = 1200 刻 × 1024 = **1228800 FE / 60 件**（旧 307200）。

**流体碎矿挖掘机**
- 每次开采注入 MILLIBUCKETS_PER_HARVEST = 100 mB；进度每刻加 drillSpeed()，
  到 20 触发一次 → 刻数 = 20 / speed → 耗电 = **1024 × 20 / speed = 20480 / speed FE / 次**。
- **算术（用户要的那一句）**：1024 FE/t × 20 刻 = **20480 FE / 100 mB**；
  100 mB = **0.1 mol** ⇒ 20480 FE / 0.1 mol = **204800 FE/mol 矿浆**（旧 51200，正好 4×）。
- **硬度 / 钻头差异怎么映射**：与旧版逐字相同 —— **只改刻数、不改每刻功耗**
  （`progress += drillSpeed()`，FluidVeinExtractorBlockEntity.java:252）。所以
  快钻头「更快且更省电」（电费与 speed 成反比），硬料只是让钻头磨得更快（wearDrill），
  不额外加价。想要"硬料更贵"就得改成按秒计价，那是另一套口径，本轮不动。
- 算例（丰度 a = 目标矿物占 100 mB 的比例）：
  - 石钻头 speed 1.00：**20480 FE / 次** → 204.8 FE/mB → **204800 FE/mol 矿浆**；
    若 a = 0.1，则目标矿物 **2048 FE/mB（≈2048000 FE/mol 矿物）**。
  - 金钻头 speed 1.80：**11378 FE / 次**（比石钻头快 1.8 倍、省电 1.8 倍）。

### 2.2 选矿类

**粉碎机**
- energyPerMillibucket() = BASE_ENERGY_PER_MB × (1 + 平均莫氏/4) = **16 × (1 + 莫氏/4)**（CrusherBlockEntity.java:452）。
- 单刻耗电 = 实际磨掉的 mB × 该系数，且单刻最多 MAX_DRAW = 256；能磨多少由
  affordable = min(energy, 256) / costPerMb 决定（:431）。**任何料都跑得满速 4 mB/t**
  （钻石 56 FE/mB × 4 = 224 ≤ 256），RATE 才是瓶颈。
- **新 FE/mB 表**（旧 = 新 ÷ 2）：

| 料（莫氏） | 旧 FE/mB | **新 FE/mB** | 旧 FE/mol | **新 FE/mol** |
|---|---|---|---|---|
| 石灰岩（3.0） | 14 | **28** | 14000 | **28000** |
| 赤铁矿（5.5） | 19 | **38** | 19000 | **38000** |
| 磁铁矿（6.0） | 20 | **40** | 20000 | **40000** |
| 花岗岩（6.5） | 21 | **42** | 21000 | **42000** |
| 钻石（10.0） | 28 | **56** | 28000 | **56000** |

- 整件路：GRIND_DRAW × GRIND_TICKS = 32 × 20 = **640 FE/件**（旧 320），与来料无关（:348-358）。
  木炭 → 4 碳粉 ⇒ **160 FE/碳粉**（旧 80）；金属锭 → 1 金属粉 ⇒ **640 FE/粉**（旧 320）。

**离心机 / 磁力筛机**
- 离心机（bug#29 已修）：只有「有浆可分层 + 两个产物罐都收得下」才取电，
  drawn = min(energy.amount, MAX_DRAW=384)；空罐 / 粉料 / 产物堵住 → drawn = 0，待机 **0 FE**。
- 磁力筛机（**特性、保留**）：只要通电就取电（空转也吃），drawn = min(energy.amount, MAX_DRAW=512)，
  因为磁场 = 本刻耗电 / 128；将来由**永磁磁铁升级**降低这段基线（TODO，:245-251）。
- 满速时每刻处理 8 mB，所以 FE/mB = drawn / 8：
  - 离心机：额定 128 → **16 FE/mB**（旧 8）；上限 384 → **48 FE/mB**（旧 24）。
  - 磁选机：额定 128 → **16 FE/mB**（旧 8）；上限 512 → **64 FE/mB**（旧 32）。
- 注意：drawn 是「这一刻吃到的电」，不是「按处理量计费」——上游给多少就吃多少（封顶 MAX_DRAW）。
  模型 §三 按额定记，对磁选机是**下限**。

   —— 碳系（主路）／金属（可选）／**桶装 CO 或 H₂**。气体走 `MolCarrier` 路径：机器从桶里
   **抽走气体 mol**，空桶原地留下，**不消耗桶本身**；抽多少 mol 记多少当量，炉内试剂池的刻度不变。

   | 气体 | 每 mol 夺走的氧 | 当量 / mol | 满桶（15 mol）当量 | 算式 |
   |---|---|---|---|---|
   | CO | 1 mol | **1.0** | **15.0** | CO + [O] → CO₂，Δn(O)=1 |
   | H₂ | 1 mol | **1.0** | **15.0** | H₂ + [O] → H₂O，Δn(O)=1 |

   与碳系同刻度：**1.0 当量 = 夺走 1 mol 氧**。碳粉记 1.0 ⇒ 本征化就是「一件碳粉 = 1 mol C」，
   正好对应 C + [O] → CO；煤炭 0.8 / 木炭 0.9 / 碳棒 1.5 是每件含碳的摩尔数。
   例：磁铁矿一炉次（100 mB）要 1.60 当量 ⇒ 抽 1.60 mol 气体（CO 桶 15 → 13.4 mol）。
   **混装非还原剂（水 / 酸）的桶、空桶一律拒收**；置换炉 / 电解炉仍不收气体桶。
   本轮**未改任何功率 / 容量 / 当量数值**，只加了一类载体与它的 mol 抽取路径。
