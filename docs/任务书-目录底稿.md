# 任务书内容结构（部分 → 页 → 小节）

> 数据来源：`manual/Manual.java`（四部分 / 36 页的骨架 + 配方挂载）、
> `client/ManualTables.java`（每页追加哪张现算表）、`lang/zh_cn.json`（中文标题与段落键）。
> **页内只有两类小节**：**正文**（语言文件里连续的 `.l1…lN` 段，没有单独的小节标题，
> 页标题即其标题）与**生成表**（表 caption 即小节标题，数据全部由代码现算）。
> 「该页生成表」列给出表的中文名与 caption lang 键；序言/章节标题的 lang 键也一并列出。

## 两级目录与页码（2026-10-19 起）

书本现在是**两级目录**，物理排列为：

1. **总目录页**（书首，不属于任何部分）：只列 **4 行**，每行「部分名 · N 页」，点了进该部分的**部分目录页**；
2. **部分目录页**：每个部分的**第一个物理页**（小节多的部分会占多页），列出该部分每个小节的标题
   与它在**部分内的首页码**，点了进正文那一条；
3. **正文**：从部分目录之后接着排；**不强制每小节换页**（分页行为与上一轮一致）。

### 页码口径

- **按部分独立编号**：页脚印 `部分名 局部页/部分总页数`，每个部分从 1 重新开始。
- **部分目录页计入该部分的总页数，且是第 1 页**（所以正文通常从 `2/N` 起）。这样每张物理页都有
  唯一、连续的局部页码；小节首页码 = `物理页 − 部分首页 + 1`。
- 为让每个部分从跨的左页开始而补的**空白页不计数、不印页脚**。
- 底栏另印全书连续页码（`全书 N / M 页`）作次要参考；书首总目录页脚印 `全书第 N 页`。
- 整跨**只在左上角印一行面包屑** `部分名 → 小节名`（右页顶部不印任何标题）；小节跨页时续页同小节。
- **搜索 / 锚点跳转**仍按逻辑页与锚点表落到物理页，与「部分内页码」是两套数，互不影响。

### 每部分页数

物理页数由 `client/ManualPager` 在打开书时按当前窗口 / GUI scale 与**现算数据表**排出来，
**不写死在代码或本文档里**（数据表行数会随化学表 / 矿表变）。下表是各部分的固定**骨架**规模
（部分目录页数按标准书页 312×196 估；窗口更矮时目录页可能再多一张）：

| 部分 | 小节数 | 部分目录页 | 部分内页码 |
| --- | --- | --- | --- |
| 前言 | 6 | 1 | 1 = 目录页，正文 2..N |
| 工业化，开始！ | 21 | 2 | 1–2 = 目录页，正文 3..N |
| 化学，进阶！ | 5 | 1 | 1 = 目录页，正文 2..N |
| 附录 | 4 | 1 | 1 = 目录页，正文 2..N |

> 总目录页 1 页，不属于四个部分；跨对齐补的空白页同样不编号。

### 常用度公式（从数据现算，不拍数字）

```
物质：S(s) = 2·R(s) + 3·D(s) + 10·A(s)
        R = 参与反应数（作反应物或产物，同一条只算一次）
        D = 下游反应数（s 作为反应物的反应条数）
        A = 1 若 s 在「全部机器可用」下从 ReactionGraph.ORE_ROOTS 可达，否则 0

反应：S(r) = 20·A(r) + 8·B(r) + Σ_{p∈产物} R(p)
        A = 1 若该反应全部反应物可达；B = 1 若全部产物可达
        ΣR = 各产物（去重）的参与反应数之和
```

两个封面页各印一份**按 S 从高到低、可点击**的排行榜；每条物质 / 反应页上也印自己的分值与
R / D / A（或 A / B / ΣR）明细。实测榜首：物质是水、盐酸、硫酸、氢氧化钠、二氧化碳…；
反应是 R10、R88、R98…（分数与排序每次都从当前数据现算）。
